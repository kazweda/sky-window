# Sky Window

目的地と時刻を選び、その地点の雲の量と動きを確認する天体観測向けの試作です。

## できること

- 地図のタップまたは地名検索で目的地を選ぶ(ズームは市全体を一望できる11まで)
- 全雲量と下層・中層・上層の雲量を、今日を含む3日間で時刻を指定して表示する
- 周辺約±130kmの雲量分布を地図に重ね、時間を進めて動きを再生する
- 雲の高さに近い上空の風から、流れる向きと速さを示す
- 暗い時間帯に全雲量30%以下が続く「観測のねらい目」を夜ごとに示す

## 動かし方

ビルドは不要です。`index.html` をブラウザで開いてください。

## テスト

```sh
node --test
```

## データと利用条件

| 用途 | 提供元 | 備考 |
|---|---|---|
| 予報・地名検索 | [Open-Meteo](https://open-meteo.com/) | 無料枠は非商用向け。出典の表示が必要 |
| 背景地図 | [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html) | 出典の表示が必要。商用利用は国土地理院コンテンツ利用規約を確認 |

公開や収益化の前に、各サービスの規約を確認してください。

## 現時点の制約

- 表示するのは予報のみで、衛星画像による実況はありません。
- 予報は1時間刻みで、周辺の雲量は約0.3度間隔の格子から補間しています。雲の形や動きは目安です。
- 流れる向きは目的地で最も雲の多い層の風から求めた目安です。
- 背景地図は、日本国外ではズーム8までしか表示されません(雲のデータは取得できます)。
- 目的地を選ぶたびに81地点分を取得するため、APIの利用回数を多めに消費します。
